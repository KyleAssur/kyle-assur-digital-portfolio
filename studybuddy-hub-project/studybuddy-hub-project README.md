# StudyBuddy Hub Project

A comprehensive ed-tech platform designed for South African university students to collaborate, share resources, and support each other's academic journey.

## Project Overview

StudyBuddy Hub is an online platform that enables university students to share study materials, form virtual study groups, and access academic support from peers. Created by students for students, with a focus on South African educational institutions.
